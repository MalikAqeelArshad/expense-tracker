## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This is just Frontend UI/UX responsive application, Later I'll connect with Backend using Node/Express and MongoDB for database.
